IPL Team Batting Performance Analysis

Project Overview

This project analyzes IPL match-related data to understand the factors influencing a team's batting performance and total runs scored.

Business Problem

IPL team management wants to understand how overs played, boundaries, pitch conditions, venue, toss decisions, and innings relate to total runs.

Objectives

- Analyze average, highest, and lowest scores.
- Understand score distribution.
- Study the relationship between overs faced and total runs.
- Study the relationship between boundaries and total runs.
- Compare runs by venue, pitch type, toss decision, and innings.
- Identify low-scoring innings.

Tools & Technologies

- Python
- Pandas
- NumPy

Dataset

File: "ipl_data.csv"
